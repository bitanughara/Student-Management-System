# 🎓 Student Management System (Java)

A simple **console-based Student Management System** built using **Core Java**. This project allows users to manage student records and calculate Higher Secondary (HS) results.

## 🚀 Features

- ➕ Add Student
- 📋 View All Students
- 🔍 Search Student by Name
- 🗑️ Delete Student
- 📊 Higher Secondary Result Calculator
- ✅ Input Validation for Marks
- 🎯 Grade & Percentage Calculation

---

## 📌 Functionalities

### Add Student
- Store Student Name
- Store Registration Number

### View Student
- Display all stored student records.

### Search Student
- Search student by name using case-insensitive comparison.

### Delete Student
- Delete a student record from the system.

### HS Result Calculator
- Accept marks of six subjects.
- Drop the lowest mark.
- Calculate total marks (out of 500).
- Calculate percentage.
- Display grade and result.

## 📈 Grade System

| Marks | Grade | Result |
|--------|-------|--------|
| 400 – 500 | A+ | Excellent |
| 300 – 399 | A | First Division |
| 225 – 299 | B | Second Division |
| 150 – 224 | C | Pass |
| Below 150 | F | Fail |

## ▶️ How to Run

1. Clone the repository

```bash
git clone https://github.com/your-username/Student-Management-System-Java.git
```

2. Open the project in VS Code or any Java IDE.

3. Compile

```bash
javac project.java
```

4. Run

```bash
java project
```
